## 一、frontmatter（6 欄）

```yaml
---
title: "論文英文全名"        # 加引號，不含斜體標記
citation: "Neuron 64(4), 510–521 (2009). doi: 10.1016/j.neuron.2009.09.029 [全文（PMC 免費閱讀）](https://pmc.ncbi.nlm.nih.gov/articles/PMC4080329/)"
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: [source, active]       # 頁型 ＋ 狀態（active | superseded | stub）；日後主題標籤也放這裡
confidence: high             # high | medium | low
---
```

**`citation` 一欄包辦出處。** 格式固定：

```
<期刊> <卷>(<期>), <起頁>–<迄頁> (<年>). doi: <DOI> [全文（PMC 免費閱讀）](<PMC 網址>)
```

- **連到免費全文，不連本機 PDF。** 本庫是公開網站，全文 PDF 不進 repo。優先用 PMC
  （`https://pmc.ncbi.nlm.nih.gov/articles/PMCxxxxxxx/`；PMC 編號可用 DOI 查
  `https://pmc.ncbi.nlm.nih.gov/tools/idconv/api/v1/articles/?ids=<DOI>&format=json`），
  其次是出版社的免費版或 bioRxiv。都沒有時只給 DOI，並在 `intake.md` 備註。
- **本機 PDF 寫在隱藏註解裡**，緊接在 frontmatter 之後，一份 PDF 一行：
  `<!-- 本機 PDF：papers/<檔名，空白編碼為 %20>.pdf -->`。`tools/scan.py` 靠它對帳；
  寫完用 `urllib.parse.unquote` 驗證檔案真的存在。
- 卷期頁缺漏時據實寫（例：`Neuroinformatics (2018, 線上先行；本 PDF 未載卷期頁). doi: …`）。
- **`citation` 的字串要與可見資料表的「出處」列一字不差**——一個給機器查詢，一個給人點。

已刪除的欄位與理由：`type`（本層全是來源頁）、`short`（檔名已含姓氏與年份）、
`journal` / `doi`（併入 `citation`）、`status`（改為 `tags` 裡的一個標籤）、
`pdf`（併入 `citation` 的連結）。
沒有 `sources`、沒有領域專屬欄位（跨領域庫用不到 `evidence` / `scale`）。

### 2.1 基本資料表（8 列）

| 列 | 規則 |
|---|---|
| **出處** | **首列。與 frontmatter 的 `citation` 一字不差，含可點的免費全文連結** |
| 日期 | 線上先行／刊期／（投稿・修訂・接受）四個日期都要 |
| 通訊作者 | 中英名 ＋ email |
| 作者 | 總人數 ＋ 標出共同第一作者 ＋ **粗體標出與本庫有關的人** |
| 機構 | 全部列出 |
| 資料庫 | 若論文釋出資料庫／程式碼，給網址 |
| 補充資料 | 列出圖表編號範圍（圖 S1–S8、表 S1–S2） |
| 編輯／審查 | Frontiers 等具名審查制的期刊要列出。**審查人有時是被比較的方法的作者**（NeuroRetriever 的審查人 Callara 即 SmRG 的作者） |

**授權必查。** 在 PDF 內搜 `Creative Commons|CC BY|open-access|distributed under`。

**授權決定能散布什麼。** 本庫是公開網站。**「可免費下載」不等於「可再散布」**：PMC 作者稿與出版社免費版的版權仍屬出版社。
所以非 CC 授權的論文只給全文連結、不放 PDF；原圖以教學與評論目的引用，逐圖標明出處（3.0b）。

| 授權 | 引言塊寫法 |
|---|---|
| 付費期刊 | 「付費期刊（版權屬出版社）。全文請由資料表「出處」列的連結到 PMC 免費閱讀（說明是作者稿或出版社版）。**本庫不散布全文 PDF。** 本頁的圖擷取自原文，版權屬原出版社，以教學與評論目的引用，每張圖下方標明出處。」 |
| CC BY | 「**本篇為 CC BY 開放取用**，圖片與 PDF 可自由使用與散布。」仍逐圖標明出處與授權 |

表下緊接引言塊：與本庫有關的作者要點名（例如 BSC 成員），再加上授權說明。

### 2.1b 體裁不同時怎麼改（本庫跨領域，不預設神經科學也不預設原著論文）

九段骨架與專業文的六節是從**原著研究論文**反推的。本庫收錄範圍不限領域，
也不限體裁，遇到別種來源時**改的是節的內容，不是節的數量**：

| 體裁 | 專業文六節怎麼對應 |
|---|---|
| 原著研究論文 | 原樣：概述／方法／結果／討論／問題與限制／未來 |
| **綜述（review）** | 方法 → **「回顧的範圍與選文標準」**；結果 → **「它整理出的分歧與共識」**。<br>重點放在「這篇綜述**沒有**收哪些、為什麼」——那才是綜述的品質所在 |
| **理論／模型論文** | 方法 → **「模型的假設與參數」**；結果 → **「推導與模擬」**。<br>「問題與限制」要問「哪些假設一旦鬆開，結論就垮」 |
| **資料集／工具發表** | 結果 → **「資料的組成與已知缺陷」**；<br>「問題與限制」要問「用這份資料做什麼分析會出錯」 |
| **專書／章節** | 六節可縮為四節（概述／內容／問題與限制／未來），但**不要刪「問題與限制」** |
| **預印本** | 同原著論文，但 `confidence` 降一級，並在資料表註明「未經同儕審查」 |

**不變的三件事，任何體裁都適用：**

1. **每張圖表都要有四件套**（原圖說／中譯／解讀）。
2. **「問題與限制」的最後一條，是本頁稽核出來、來源自己沒處理的問題。**
3. **「未來」的第二段固定寫本庫的後續**（這篇留下的開口由庫內哪幾篇接手）。

**不得為了某個領域新增欄位。** 曾經草擬過 `evidence`（LM/EM/model/inferred）與
`scale`（single-neuron/LPU/synapse/whole-brain），在確認本庫跨領域後刪除——
它們在別的領域是噪音。若某個領域真的需要額外維度，用 `tags` 承載，不要動 frontmatter 的欄位。

### 2.2 摘要段

原文照抄，保留 Background / Results / Conclusion 分段。中譯前**必須**寫：

```
**中譯**（本節為忠實翻譯，非自撰內容）：
```

這是全頁唯一的翻譯內容，必須自我標示。

### 2.3 科普文（約 1,700 字，高中生程度）

- **以類比開場，不以定義開場。** 實例第一句是「想像你要畫一張城市的道路圖」，
  之後整段用「城市＝腦、路線＝神經元」貫穿。
- 依「**難題 → 解法 → 代價**」推進，不依論文章節順序。
- 專有名詞首次出現寫「中文（English）」。
- 段落結尾用粗體收束該段的一句話重點。
- **最後一段留給最容易被誤讀的一點。**
  實例：「這是關於『取樣夠不夠』的論證，不是關於『做完了沒有』的宣稱。」

### 2.4 專業文（約 6,000 字，研究生程度，六節固定）

```
### 一、概述       三個粗體引導：主要問題／重要性／發表當時的領域現狀（標年份）
### 二、方法       以 mermaid 流程圖開場，再逐段展開參數
### 三、結果       再分 #### 3.1…3.6：資料規模 → 精度 → 主要發現 → 網路 → …
### 四、討論       論文的主張，逐條評價其強弱
### 五、問題與限制  編號列出
### 六、未來       三段（見下）
```

- **「領域現狀」要標年份並引具體文獻**（White et al. 1986、Bohland et al. 2009…），
  把這篇放進當時的座標，不是泛談背景。
- **「方法」要寫出補充資料裡的參數**：實例寫進了 37 °C 熱休克 3–60 分鐘、
  40× NA 1.2、體素 0.32×0.32×1 µm——這些正文都沒有。
- **「問題與限制」的最後一條，是本頁稽核出來、論文自己沒處理的問題。**
  前幾條是論文自陳的限制，最後一條是本庫的貢獻。
  實例第 7 條：摘要說 six hubs、正文列四對、Figure 5A 標「−」的有九個。
- **「未來」固定三段**：論文自陳的方向／**本庫關注的後續**（這篇留下的開口
  由庫內哪幾篇接手）／尚未被回答的。

## 三、圖：每張四件套

### 3.0 先確認圖是完整的（Kaleido 2018 學到的）

`pdfimages` 抽的是 PDF 裡**內嵌的點陣影像**。期刊排版常把複合圖拆成
「一張大點陣圖 ＋ 一堆向量／文字元件」，於是分格標籤（A/B/C）、色階圖例、
箭頭標示、圖上數字**全部抽不到**，而 `extract.sh` 的小圖濾網又會把小分格刪掉。

**判準：拿抽出的圖對照圖說。圖說提到而圖上找不到的東西，就是漏了。**

> ⚠️ **最容易犯的錯：把「抽圖不完整」誤判成「論文的圖有缺陷」。**
>
> 寫 Kaleido 2018 時，抽出的 Figure 2 缺了 A/B/C 分格字母、1–3 號箭頭與全部箭頭，
> 於是解讀裡寫了「圖說指涉的箭頭在圖上找不到，讀者無從知道作者要指哪幾顆」
> 與「B 與 C 的差異需要非常仔細才看得出來」。**兩句都是錯的**——
> 箭頭一直都在，而且三對箭頭清楚示範了隨機配色會讓相鄰細胞體同色。
>
> **規則：在指控論文的圖有缺陷之前，一定要先用整頁渲染確認一次。**
> 「圖說提到但圖上沒有」這句話，只有在看過 300 dpi 整頁渲染之後才能寫。

**裁切也會製造同樣的錯誤。** LYNSU 五張圖初次裁切時上緣過低，A–F 的分格字母被切掉一半，
對照圖說時分不出哪格是哪格。**裁完必用 Read 看一次，確認四個角落與所有分格字母都在。**

漏了就改用整頁渲染：

```bash
pdftoppm -f N -l N -r 300 -jpeg "papers/檔名.pdf" .cache/<slug>/hi
python3 -c "
from PIL import Image
im=Image.open('.cache/<slug>/hi-N.jpg'); w,h=im.size
im.crop((int(w*0.13),int(h*0.435),int(w*0.87),int(h*0.815))).save('assets/名字.jpg',quality=92)"
```

裁切比例先看 150 dpi 的 `page-N.jpg` 目視定位，再套到 300 dpi 版。
**裁完要用 Read 看一次確認沒切到標題或切掉圖例。**

### 3.0b 四件套的順序

順序不可換。**圖下方的出處行是本庫公開網站的必要條件，不可省略**（CC 授權者把「教學引用」改成授權名稱）：

```markdown
![Figure 5D：中文說明](../../assets/chiang2011-fig5.jpg)

<small>圖片出處：作者（全部，或前三位 et al.）. *期刊* 卷(期):頁 (年)，Figure 5。© 年 出版社 教學引用；全文見 [PMC](<PMC 網址>)。</small>

> **原圖說（Figure 5）：** 英文原文照抄，含 (A)(B)(C)(D) 分項

**圖說中譯：** 逐項翻譯，保留 (A)(B)(C)(D) 編號

**解讀：** ← 本庫的產出
```

### 3.1 「解讀」的前五條判準（全頁最吃工的部分；第六條見 3.2）

逐條對照著寫。**一句都不要複述圖說。**

1. **寫出正文沒說的東西。**
   實例 Fig 4C：正文只有定性的 "at the expense of"，圖上有 2.7/3.61 µm →
   5.05/4.09 µm，解讀把它算成「精度升三成，是用區域外離散增五成換的」。
2. **指出這張圖真正該看的地方**——常常不是作者強調的地方。
   實例 Fig 6：「F 圖是全篇最重要的一張圖，卻最常被略過。」
3. **指出圖與正文對不上之處。**
   實例 Fig 5：「A 圖那張正負號表與正文的敘述對不上。」
4. **指出視覺陷阱。**
   實例 Fig 3：「縱軸是對數尺度，視覺上相近的柱高其實差一個數量級。」
   實例 Fig 8：「擷取出的圖上沒有可辨識的圖例。」
5. **對過度解讀踩煞車。**
   實例 Fig 6：「冪律的擬合範圍只跨約一個數量級，以此宣稱無尺度性質是薄弱的。」

### 3.2 「解讀」的第六條：拿論文自己的數字，算出它沒報告的量

寫完六篇之後，最有價值的解讀幾乎都來自同一個動作：**論文報告了 A 和 B，
但真正該看的是 f(A, B)，而論文沒算。**

| 論文 | 論文報告的 | 推算出來的 |
|---|---|---|
| Shih 2019 | TPR = 0.40、FPR = 0.02，評語「偽陽性極低」 | **精確率約 15%**（FPR 的分母是無連結配對數，在稀疏網路中極大）。每五條預測連結約一條為真 |
| Shih 2019 | 圖 3d 各社群全域中心性**總分** | 除以社群人數後**排序翻轉**：前運動由第一掉到第四 |
| Kaleido 2018 | 色相環均分、*N* = 10,000 | 相鄰色相僅差 **0.036°**，遠低於人眼閾值。「一萬顆可區分」只能是局部的 |
| NeuroRetriever | GS 公式（式 12）＋ 精確率定義（式 11） | **式 12 不含精確率**，故不懲罰「切太多」；相符型的精確率峰值僅 0.35–0.45 |
| LYNSU 2024 | 六結構 IoU ＋ 標註者一致度 0.85 | **平均 0.833 低於 0.85**；只有兩個結構超過人的一致度 |
| LYNSU 2024 | 圖 5A 兩張直方圖 | 左側較大者約 490 vs 右側 390（*z* ≈ 3.4）→ **不對稱有方向性**，論文只報比率未報方向。<br>※ 但「幅度也偏左」不成立——重判後左 22、右 17，在判讀誤差內。**個數成立、幅度不成立，要分清楚** |

**做法：每讀到一個比率或評語，先問「分母是什麼」「有沒有除以樣本數」
「有沒有可比的基準線」。** 三個問題各對應上表的一類。

### 3.3 表格：重製，並加上論文沒並列的那一列

規則不只是「重製為中文表」，而是**重製時把決定解讀的參照值補進去**。

LYNSU 的例子最清楚：論文的 Figure 4C 只有兩列（3D U-Net、LYNSU），
補上第三列「標註者之間 = 0.85」之後，摘要「與專業人工標註相當」立刻可以被檢驗。
那個 0.85 就寫在方法一節，論文只是沒有跟結果並列。

同理：Shih 2019 的 Table 1 補上「社群人數」欄之後，才看得出三個非小世界社群
同時是最小且最密的三個。

## 四、表格與流程圖

**表格**：由圖或補充表**重製為中文表格**，不是截圖。每張表下方緊接引言塊，
交代來源與驗算：

```
> 依 Figure 1B 逐項讀出並驗算。雌性扣除 Others 後為 12,514，即 Table S1 之總計。
```

有合計列時用粗體，並讓讀者能自行驗算。

**mermaid**：只用在步驟型內容（整體管線 `flowchart TD`、子流程 `flowchart LR`）。
節點內用 `<br/>` 換行，**把參數寫進節點**：`"共軛焦取像<br/>40× NA1.2，體素 0.32×0.32×1 µm"`。
不用 mermaid 畫資料圖。

## 五、頁尾

