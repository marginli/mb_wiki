## 階段一（2026-10-25）：從母庫移植規範，三篇平行收錄

**做了什麼。** 本庫的規範、工具與收錄流程整套移植自母庫 `research_with_AI`，只改了三件事：範圍改為果蠅蘑菇體研究；授權改為「GitHub 私有 repo，以協作者身分開放給同事」，PDF 與原圖都進 repo；網站改為本機 8788 埠，不再依賴母庫的 Tailscale 與 systemd 設定。三篇論文由三個 agent 平行各寫一篇來源頁，共用檔（數字簿、索引、登記簿、日誌）由整合者最後統一合併，避免互相覆寫。

**被什麼逼著改。**

1. **母庫預設「每篇收錄前停下來討論」。** 使用者這次指定批次收錄、事後一次回報，依 `ingest-paper` skill 的例外條款處理。矛盾仍照規則標記、等人裁決，沒有因為批次而自行圓說法。
2. **三份 PDF 都不含補充資料，而且自動下載被擋。** PMC 的下載頁有反機器人驗證，Europe PMC 的 API 回報這三篇「不是開放取用」。本庫沒有繞過驗證，改為在來源頁把只在補充資料的內容一律標 `？待查（補充資料未取得）`，並在登記簿備註欄留下待人工下載的紀錄。
3. **使用者的全域寫作規則要求頁面「第一版就讓外行讀得懂」。** 三篇來源頁各自跑了 2 到 5 輪冷讀（沒有背景的讀者從頭讀、列出看不懂的地方、改寫後換新讀者再讀），直到沒有「看不懂」為止。冷讀第二輪以後，讀者開始抓到真正的內容錯誤，而不只是文字問題（見下方乙類第 1 條）。
4. **`.cache/` 不進 repo。** 來源頁原本用抽取文字檔的行號標出處，同事 clone 下來看不到，三篇都改成「PDF 第 N 頁」或圖號。數字簿保留行號，並在頁首說明如何重建抽取檔。

**主題的判定。** 三篇都落在「多巴胺如何改變 KC→MBON 突觸」這一條線上，依開頁門檻（至少兩篇對它有實質的話要說，而且說的不一樣）開了兩條主題：[[t-timing-rules]]（先後與間隔）與 [[t-dopamine-to-plasticity]]（受體、第二傳訊者、區室、突觸哪一側）。概念與實體依「至少兩篇實際使用」開了 15 頁，未過門檻的留在各來源頁的「待開頁面」清單。

## 階段二（2026-10-25）：從私有 repo 改為公開網站

**做了什麼。** 使用者希望同事只要有連結就能看，並決定採用公開網站：全文 PDF 不放，改連 PMC；原圖保留並逐圖標明出處。於是：

- 三篇來源頁的「出處」從本機 PDF 連結改為 PMC 免費全文連結；本機 PDF 檔名移到 frontmatter 之後的隱藏註解，`tools/scan.py` 改讀這個註解，對帳照樣成立。
- 21 張圖下方各加一行出處（作者、期刊、卷期頁、年份、圖號、版權持有者、全文連結）。
- `papers/*.pdf` 加進 `.gitignore`，並從尚未推出的第一個 commit 中移除，歷史紀錄裡沒有 PDF。`tools/build_site.py` 不再把 `papers/` 連進網站。
- 新增 GitHub Pages 自動部署（`.github/workflows/pages.yml`），部署前檢查網站裡沒有 PDF。
- `CLAUDE.md`、頁面規格、範本與 README 改寫為公開網站的版本。

**被什麼逼著改。** 使用者原本選擇「PDF 與原圖都進私有 repo」，後來改為「只要連結就能看」。本庫在對話中說明了「可免費閱讀不等於可再散布」，以及教學用途的合理使用通常以「限定對象」與「必要範圍」為前提。最後的折衷是：全文只給連結，原圖以教學引用並標出處。**這是使用者的決定；本庫不提供法律意見。**

## 階段三（2026-10-25）：第二批五篇，新增一個研究問題群

**做了什麼。** 本庫收錄果蠅蘑菇體（腦中把氣味和好壞結果連起來的區域）的研究論文，每篇論文寫一頁「來源頁」，再把多篇對同一問題的說法整合成「主題頁」。使用者在 `papers/` 放進五篇：Cohn 2015、Ichinose 2015、Aso & Rubin 2016、Felsenberg 2017、Felsenberg 2018。流程和階段一相同：五個 agent 平行各寫一篇來源頁（各自冷讀 3–4 輪；冷讀＝讓沒有背景的新讀者從頭讀、列出看不懂的地方，改寫後換人再讀），再由四個 agent 平行整合，分別負責兩條新主題、兩條既有主題的改寫、以及全部概念與實體頁；共用檔（數字簿、矛盾頁、本頁、索引、登記簿、日誌、README）與來源頁之間的交叉引用由整合者處理。

**被什麼逼著改。**

1. **五篇裡有四篇談的不是「突觸怎麼改」，而是「記憶寫下之後發生什麼」。** 依本庫的規範檔 `CLAUDE.md`，研究問題不同就在索引另開一節（研究問題群）：`index.md` 加一個 H2「記憶寫入之後：鞏固、更新與迴路回饋」，`tags` 值 `mb-memory-dynamics`，沒有新增欄位或目錄。兩條新主題 [[t-memory-updating]]（三篇主要來源）與 [[t-mbon-dan-feedback]]（四篇）都過了開主題頁的門檻（至少兩篇論文對它有實質的話要說，而且說的不一樣；只有一篇或說法都一樣，就不必另寫一篇整合文章）。
2. **平行整合需要事先定案的共用名單。** 上一批的教訓是平行撰寫的頁看不到彼此。這一批在整合開工前，先寫好一份共用說明：新頁的頁名、矛盾的編號、哪個 agent 擁有哪些檔、以及已知要更正的句子。主題頁只連結名單上的頁，實體頁 agent 另外依門檻判定其餘候選。結果核心名單九頁全部過門檻，另有十五頁由回查各來源頁的「待開頁面」清單後開出。
3. **概念與實體頁從 15 頁增為 39 頁。** 多數新頁是細胞型（某一型神經元，例如輸出神經元 [[e-mbon-gamma1pedc]]）與驅動品系（決定實驗操作的是哪幾型神經元的基因工具，代號如 [[e-r58e02]]）。第二批的論文大量共用同一批品系與細胞，而「某個品系到底標到哪幾型神經元」正是三條新矛盾的來源（[[syn-contradictions]] 1.4–1.6）。
4. **上一批刻意留著的 ？待查，這一批被填上。** 蘑菇體的主要神經元 Kenyon 細胞（KC）有多少顆，階段一被刪了兩次（見下方壬類第 1、4 條：兩頁都憑記憶補了「約兩千」，原文沒有）。這一批 Aso 2016 與 Cohn 2015 的引言都寫了約 2,000，[[e-mushroom-body]] 改為引用這兩篇，並註明兩篇都是轉述他人的研究。「標了 ？待查就不要填」的規則在這裡第一次兌現。
5. **授權不再只有一種。** 三篇（Ichinose 2015、Aso 2016、Felsenberg 2018）是 CC BY，依 `CLAUDE.md` 可以放 PDF；本庫為了規則單純，仍不放任何 PDF，只在圖片出處行與 README 標明授權。
6. **撰寫用的 AI 子程序（subagent）不能寫交接報告檔。** 交接報告是給下一次接手的人看的筆記。五個來源頁 agent 寫入時都被執行環境（Claude Code 的 harness）擋下，改在回覆中交出報告，由整合者代存。兩個 agent 一度共用同一個暫存子目錄，互相覆蓋了冷讀前的備份；事後比對確認沒有數字或引用遺失，整合階段起每個 agent 用自己的子目錄。

**新的待裁決矛盾 4 條**（[[syn-contradictions]] 1.3–1.6）：1.3 來自刺激參數（兩篇用不同的時間間隔與強度活化多巴胺神經元），1.4–1.6 來自品系或細胞身分的描述。沒有一條是「兩篇用同樣的方法量同一件事、得到相反結果」。※ 推論：這一批的論文共用工具的程度遠高於第一批，矛盾因此集中在「工具到底標了誰」這一層。

## 本庫更正過自己的地方

分類沿用母庫的九類，第二批另開兩類（癸、子）。各類的「第二批」條目是 2026-10-25 第二批收錄時抓到的。**以下全部在發布前被抓到**，有的由撰寫者自己回查原文推翻，有的由冷讀者指出，有的由整合者抽查發現。

### 乙、從圖判讀出來的數值與換算（9 處）

1. [[s-tomchik-2009-camp-dynamics]] 原寫「以氣味開始為準，行為與成像的時間窗差一個數量級」。第二輪冷讀者指出成像 30 秒對行為 60–75 秒只差 2–3 倍，已更正，交接報告同步。
2. [[s-hige-2015-heterosynaptic-plasticity]] 原寫「γ1 與 α2 的誘發門檻相差 120 倍」。α2 只測了 4 下（無效）與 120 下（有效）兩點，改為「超過 4 倍，上限未知」。
3. [[s-hige-2015-heterosynaptic-plasticity]] 科普文的「未配對氣味應少掉多少」估算，原本混用了放電次數與電流兩種指標，得到 0.85。冷讀者指出後改為只用放電：0.3 × 0.8 ≈ 0.24，與專業文的 24–30% 一致。
4. [[s-handler-2019-dopamine-receptor-timing]] 圖 5F 的重算值，內質網鈣標準化後原寫 0.13，應為 0.11，相減結果全部重算，數字簿同步。
5. [[s-handler-2019-dopamine-receptor-timing]] 原寫「PPL 的翻轉點比 PAM 晚約 1 秒」，是用區間中點推算（實際差 1.5 秒）。改用線性內插：+0.49 秒對 −0.44 秒，差約 0.9 秒。
6. [[s-handler-2019-dopamine-receptor-timing]] 與數字簿寫「順向配對的 cAMP 比逆向高約 25–35%」。矛盾頁的第二輪冷讀者驗算：0.122 ÷ 0.095 ≈ 1.28、0.15 ÷ 0.11 ≈ 1.36，應為 28–36%。已 grep 舊值，全庫同步更正並確認零殘留。
7. （第二批）[[s-felsenberg-2017-re-evaluation]] 原寫圖 2b 冷休克延後 90 分鐘的組「完全恢復」。柱高只回到未冷休克組的約六成、未達顯著差異，改為「部分恢復」。
8. （第二批）[[s-aso-2016-dan-cell-type-rules]] 圖 5A 的 n.d.（未測）格數，初稿數成 12，重數為 9。
9. （第二批）[[s-cohn-2015-coordinated-neuromodulation]] 原由圖 7F 的 γ4／γ2 比值推出 γ4 變化的「上限」。冷讀者指出比值無法界定單一格的變化，已刪。

### 丙、宣稱唯一性（3 處）

1. [[s-tomchik-2009-camp-dynamics]] 的「為什麼重要」寫了「本篇是第一批用遺傳編碼 cAMP 感測器在果蠅腦裡看見這件事的研究之一」。原文沒有這樣的優先權宣稱，改為引述作者自己的措辭。由整合者在第二輪冷讀修改時發現。
2. （第二批）[[s-felsenberg-2017-re-evaluation]] 初稿寫「本庫第一篇用阻斷操作 DAN」，撰寫者自己依寫作紀律第 10 條刪除。
3. （第二批）[[t-timing-rules]] 原寫「完整的時間差掃描只有 Handler 2019 在 γ4 格做過」。Aso 2016 在行為上對單一型 DAN 掃了十個時間差，改為「突觸層級只有 Handler 2019」。

### 丁、把論文的條件句或引用讀成斷言（6 處）

1. [[s-tomchik-2009-camp-dynamics]] 原把正文「多巴胺的反應在 11.9% 飽和」讀成感測器本身的上限。圖 2B、2D 顯示 forskolin 可達約 40%，改為「多巴胺能啟動的 cAMP 上限」，並據此說明配對反應沒有撞到感測器天花板。
2. [[s-handler-2019-dopamine-receptor-timing]] 原把「DopR2 即 DAMB」當成論文明說。grep 後只出現在參考文獻與抗體名稱中，改寫為非論文明說。
3. [[s-handler-2019-dopamine-receptor-timing]] 圖 1G 的 +4.2 mm 與正文「稍微增強」原判為矛盾。重讀方法後，變化量是相對前一次測試算的，而前一次已被逆向配對壓低，改判為不矛盾。
4. （第二批）[[c-mb-compartment]] 原寫「每格的 DAN 只調整自己那一格」，[[t-dopamine-to-plasticity]] 的導言與第三環寫「聲音只傳遍他負責的那一段」「效果不外溢」。Hige 2015 只測了兩組相鄰格；Cohn 2015 圖 6E 在別格量到小幅、方向相反的效果。三處都改為「主要」並註明例外。
5. （第二批）[[t-timing-rules]] 原寫「決定學不學得到的時間窗在行為上以數十秒計，決定往哪個方向學的時間窗在突觸上以一秒計」。這是把兩篇並排得到的條件句寫成規則；Aso 2016 在行為上看到方向本身在數十秒尺度翻轉，改為只對那兩組條件成立。
6. （第二批）[[s-cohn-2015-coordinated-neuromodulation]] 的術語表與交接報告把 58E02 寫成「在 γ4、γ5 的 DAN 表現」。原文第一次介紹時是「a subset of DANs, including those innervating the γ4 and γ5」，「包括」不是「只有」。由實體頁 agent 回查原文指出，整合者改正來源頁與 [[syn-contradictions]] 1.5。

### 戊、其他：數錯、混數、誤認資料（15 處）

1. [[s-tomchik-2009-camp-dynamics]] 3.2 節原寫「同一群細胞、同一次給藥，樹突與軸突結果不同」。第一輪冷讀者抓出前後矛盾，回查圖 3D 圖說，萼部與葉部的紀錄來自兩組不同的腦，改為「組間比較，證據比字面弱」。
2. [[s-tomchik-2009-camp-dynamics]] 章魚胺配對實驗原寫「四個條件中三個顯著」，圖 5J 有五個條件，改為「五個中三個」。
3. [[s-tomchik-2009-camp-dynamics]] 原以為圖 6 的 1 秒延遲與圖 5 是同一組資料，但 n（7 vs 11）與柱高都不同，改為「是否獨立未說明」。
4. [[s-hige-2015-heterosynaptic-plasticity]] 原寫「六個實驗中有四個未配對氣味顯著下降」，是把兩類實驗混在一起數，改為分開列。
5. [[s-handler-2019-dopamine-receptor-timing]] 圖 4F 圖說寫 n ＝ 27，原以為是點數；由 p 值反推約 54 點，應為 27 輪 × 2。
6. 整合者交辦實體頁時，把 Handler 2019 的 R58E02 寫成 split-GAL4 品系。撰寫 [[e-split-gal4]] 的 agent 回查基因型表後指出：R58E02 在該篇是 LexA 品系（驅動 P2X2），或是 MB042B 這個 split-GAL4 的其中一半，本身不是 split-GAL4。頁面依原文寫。
7. [[t-timing-rules]] 初稿的逆向配對表，把 Handler 2019 的 γ4 突觸結果（活化 PAM）與行為結果（活化 PPL）並排，讀者推不出方向。第二輪冷讀者指出後拆成 PAM 與 PPL 兩列，各自對照方向。
8. [[t-timing-rules]] 初稿寫「Hige 2015 與 Handler 2019 都用光遺傳學活化多巴胺神經元」。Handler 2019 的離體實驗用的是 P2X2 通道加 ATP 的化學方法，光遺傳只用在行為與閉迴路實驗，已改正。
9. （第二批）[[s-cohn-2015-coordinated-neuromodulation]] 3.3 節原寫「五種 MBON」，實為 4 個 MBON 加一列 DAN，冷讀者指出。
10. （第二批）[[s-felsenberg-2017-re-evaluation]] 把一個 LexA 品系（R65B09）標到的 MBON 型別寫錯，第三輪冷讀者指出後依延伸圖 6l 更正。
11. （第二批）[[s-felsenberg-2018-memory-extinction]] 初稿把圖 S2B 當成 PAM 實驗的「只升溫」對照，實為 VT1211 品系的對照。改正後成為一條新的限制：PAM 那組沒有「升溫但不再暴露」的對照。另有兩處頁碼由第 9 頁改為第 8 頁。
12. （第二批）[[s-aso-2016-dan-cell-type-rules]] 初稿把「保留組」與「訓練後再活化 DAN 組」寫成同一群果蠅由約 −0.65 降到約 −0.2，實為兩組不同的果蠅，改為並列。

## 一個貫穿兩批的模式

**階段一。** 上方壬類「憑記憶補充事實」的前九條都在來源頁上，全部出現在**科普文與「為什麼重要」**，也就是寫給外行讀者、需要背景鋪陳的段落。第十到十二條出現在實體頁與主題頁的撰寫與冷讀改寫中，同樣是為了讓外行讀懂而補的一句背景。專業文緊貼原文，反而很少出這種錯。※ 推論：越是想讓讀者讀懂，越容易順手補一句「大家都知道」的背景，而那一句正好沒有出處。之後收錄時，背景句要和數字一樣先問「出處在哪」。

**第二批。** 共用說明裡特別提醒了這一類錯，來源頁 agent 只犯了一處（壬類第 13 條），而且是撰寫者在交件前自己抓到的。整合者卻又犯了一次（第 14 條），位置同樣是為讀者補的背景句。新出現的兩類錯（癸、子）都和「工具」有關：一類是把一篇論文對品系的描述當成定論，另一類是抽取文字時吃掉了符號。兩者的檢查動作相同，都是回到原始的頁面去看，而不是信任中間產物。
