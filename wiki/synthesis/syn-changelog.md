## 階段一（2026-10-25）：從母庫移植規範，三篇平行收錄

**做了什麼。** 本庫的規範、工具與收錄流程整套移植自母庫 `research_with_AI`，只改了三件事：範圍改為果蠅蕈狀體研究；授權改為「GitHub 私有 repo，以協作者身分開放給同事」，PDF 與原圖都進 repo；網站改為本機 8788 埠，不再依賴母庫的 Tailscale 與 systemd 設定。三篇論文由三個 agent 平行各寫一篇來源頁，共用檔（數字簿、索引、登記簿、日誌）由整合者最後統一合併，避免互相覆寫。

**被什麼逼著改。**

1. **母庫預設「每篇收錄前停下來討論」。** 使用者這次指定批次收錄、事後一次回報，依 `ingest-paper` skill 的例外條款處理。矛盾仍照規則標記、等人裁決，沒有因為批次而自行圓說法。
2. **三份 PDF 都不含補充資料，而且自動下載被擋。** PMC 的下載頁有反機器人驗證，Europe PMC 的 API 回報這三篇「不是開放取用」。本庫沒有繞過驗證，改為在來源頁把只在補充資料的內容一律標 `？待查（補充資料未取得）`，並在登記簿備註欄留下待人工下載的紀錄。
3. **使用者的全域寫作規則要求頁面「第一版就讓外行讀得懂」。** 三篇來源頁各自跑了 2 到 5 輪冷讀（沒有背景的讀者從頭讀、列出看不懂的地方、改寫後換新讀者再讀），直到沒有「看不懂」為止。冷讀第二輪以後，讀者開始抓到真正的內容錯誤，而不只是文字問題（見下方乙類第 1 條）。
4. **`.cache/` 不進 repo。** 來源頁原本用抽取文字檔的行號標出處，同事 clone 下來看不到，三篇都改成「PDF 第 N 頁」或圖號。數字簿保留行號，並在頁首說明如何重建抽取檔。

**主題的判定。** 三篇都落在「多巴胺如何改變 KC→MBON 突觸」這一條線上，依開頁門檻（至少兩篇對它有實質的話要說，而且說的不一樣）開了兩條主題：[[t-timing-rules]]（先後與間隔）與 [[t-dopamine-to-plasticity]]（受體、第二傳訊者、區室、突觸哪一側）。概念與實體依「至少兩篇實際使用」開了 15 頁，未過門檻的留在各來源頁的「待開頁面」清單。

## 階段二（2026-10-25）：從私有 repo 改為公開網站

**做了什麼。** 使用者希望同事只要有連結就能看，並決定採用公開網站：全文 PDF 不放，改連 PMC；原圖保留並逐圖標明出處。於是：

- 三篇來源頁的「出處」從本機 PDF 連結改為 PMC 免費全文連結；本機 PDF 檔名移到 frontmatter 之後的隱藏註解，`tools/scan.py` 改讀這個註解，對帳照樣成立。
- 21 張圖下方各加一行出處（作者、期刊、卷期頁、年份、圖號、版權持有者、全文連結）。
- `papers/*.pdf` 加進 `.gitignore`，並從尚未推出的第一個 commit 中移除，歷史紀錄裡沒有 PDF。`tools/build_site.py` 不再把 `papers/` 連進網站。
- 新增 GitHub Pages 自動部署（`.github/workflows/pages.yml`），部署前檢查網站裡沒有 PDF。
- `CLAUDE.md`、頁面規格、範本與 README 改寫為公開網站的版本。

**被什麼逼著改。** 使用者原本選擇「PDF 與原圖都進私有 repo」，後來改為「只要連結就能看」。本庫在對話中說明了「可免費閱讀不等於可再散布」，以及教學用途的合理使用通常以「限定對象」與「必要範圍」為前提。最後的折衷是：全文只給連結，原圖以教學引用並標出處。**這是使用者的決定；本庫不提供法律意見。**

## 階段三（2026-10-25）：第二批五篇，新增一個研究問題群

**做了什麼。** 本庫收錄果蠅蕈狀體（腦中把氣味和好壞結果連起來的區域）的研究論文，每篇論文寫一頁「來源頁」，再把多篇對同一問題的說法整合成「主題頁」。使用者在 `papers/` 放進五篇：Cohn 2015、Ichinose 2015、Aso & Rubin 2016、Felsenberg 2017、Felsenberg 2018。流程和階段一相同：五個 agent 平行各寫一篇來源頁（各自冷讀 3–4 輪；冷讀＝讓沒有背景的新讀者從頭讀、列出看不懂的地方，改寫後換人再讀），再由四個 agent 平行整合，分別負責兩條新主題、兩條既有主題的改寫、以及全部概念與實體頁；共用檔（數字簿、矛盾頁、本頁、索引、登記簿、日誌、README）與來源頁之間的交叉引用由整合者處理。

**被什麼逼著改。**

1. **五篇裡有四篇談的不是「突觸怎麼改」，而是「記憶寫下之後發生什麼」。** 依本庫的規範檔 `CLAUDE.md`，研究問題不同就在索引另開一節（研究問題群）：`index.md` 加一個 H2「記憶寫入之後：鞏固、更新與迴路回饋」，`tags` 值 `mb-memory-dynamics`，沒有新增欄位或目錄。兩條新主題 [[t-memory-updating]]（三篇主要來源）與 [[t-mbon-dan-feedback]]（四篇）都過了開主題頁的門檻（至少兩篇論文對它有實質的話要說，而且說的不一樣；只有一篇或說法都一樣，就不必另寫一篇整合文章）。
2. **平行整合需要事先定案的共用名單。** 上一批的教訓是平行撰寫的頁看不到彼此。這一批在整合開工前，先寫好一份共用說明：新頁的頁名、矛盾的編號、哪個 agent 擁有哪些檔、以及已知要更正的句子。主題頁只連結名單上的頁，實體頁 agent 另外依門檻判定其餘候選。結果核心名單九頁全部過門檻，另有十五頁由回查各來源頁的「待開頁面」清單後開出。
3. **概念與實體頁從 15 頁增為 39 頁。** 多數新頁是細胞型（某一型神經元，例如輸出神經元 [[e-mbon-gamma1pedc]]）與驅動品系（決定實驗操作的是哪幾型神經元的基因工具，代號如 [[e-r58e02]]）。第二批的論文大量共用同一批品系與細胞，而「某個品系到底標到哪幾型神經元」正是三條新矛盾的來源（[[syn-contradictions]] 1.4–1.6）。
4. **上一批刻意留著的 ？待查，這一批被填上。** 蕈狀體的主要神經元 Kenyon 細胞（KC）有多少顆，階段一被刪了兩次（見下方壬類第 1、4 條：兩頁都憑記憶補了「約兩千」，原文沒有）。這一批 Aso 2016 與 Cohn 2015 的引言都寫了約 2,000，[[e-mushroom-body]] 改為引用這兩篇，並註明兩篇都是轉述他人的研究。「標了 ？待查就不要填」的規則在這裡第一次兌現。
5. **授權不再只有一種。** 三篇（Ichinose 2015、Aso 2016、Felsenberg 2018）是 CC BY，依 `CLAUDE.md` 可以放 PDF；本庫為了規則單純，仍不放任何 PDF，只在圖片出處行與 README 標明授權。
6. **撰寫用的 AI 子程序（subagent）不能寫交接報告檔。** 交接報告是給下一次接手的人看的筆記。五個來源頁 agent 寫入時都被執行環境（Claude Code 的 harness）擋下，改在回覆中交出報告，由整合者代存。兩個 agent 一度共用同一個暫存子目錄，互相覆蓋了冷讀前的備份；事後比對確認沒有數字或引用遺失，整合階段起每個 agent 用自己的子目錄。

**新的待裁決矛盾 4 條**（[[syn-contradictions]] 1.3–1.6）：1.3 來自刺激參數（兩篇用不同的時間間隔與強度活化多巴胺神經元），1.4–1.6 來自品系或細胞身分的描述。沒有一條是「兩篇用同樣的方法量同一件事、得到相反結果」。※ 推論：這一批的論文共用工具的程度遠高於第一批，矛盾因此集中在「工具到底標了誰」這一層。

### 乙、從圖判讀出來的數值與換算（18 處）

1. [[s-tomchik-2009-camp-dynamics]] 原寫「以氣味開始為準，行為與成像的時間窗差一個數量級」。第二輪冷讀者指出成像 30 秒對行為 60–75 秒只差 2–3 倍，已更正，交接報告同步。

## 一個貫穿兩批的模式

**階段一。** 上方壬類「憑記憶補充事實」的前九條都在來源頁上，全部出現在**科普文與「為什麼重要」**，也就是寫給外行讀者、需要背景鋪陳的段落。第十到十二條出現在實體頁與主題頁的撰寫與冷讀改寫中，同樣是為了讓外行讀懂而補的一句背景。專業文緊貼原文，反而很少出這種錯。※ 推論：越是想讓讀者讀懂，越容易順手補一句「大家都知道」的背景，而那一句正好沒有出處。之後收錄時，背景句要和數字一樣先問「出處在哪」。

## 階段六（2026-11-12）：第一篇不做實驗的來源

同日收錄的第二篇（Minnick 等 2026）在兩方面是本庫的第一次。

**第一，它不做實驗。** 它把一整份果蠅連結體（BANC，腦加腹神經索，172,433 顆神經元）原樣跑成脈衝網路，神經元與突觸的參數沿用 Shiu 等人已發表的值、沒有為 Minnick 2026 重新調整（介面與學習規則是作者事先訂好的固定規則；唯一對著實驗值調整的，是把一類嗅葉局部神經元的輸出縮成 0.15 倍），再放進模擬的身體裡。本庫原有的來源都是在活果蠅或取出的腦上量測，所以此前所有頁面的「怎麼用」欄位預設的都是實驗操作。收錄它沒有動到任何規則——`CLAUDE.md` 早就寫明「分子訊號、電生理、成像、行為、連結體、模型都在範圍內，子領域不同不另立規則」——但 [[syn-contradictions]] 4.3 新增了一段說明：模型符合實驗不等於獨立證實，模型不符合實驗通常是在指出模型缺了什麼。

**第二，它是本庫第一篇只收錄一部分的來源。** Minnick 2026 全文 42 頁、六張主圖，大半在講導航與運動控制，與蕈狀體無關。來源頁因此只完整處理蕈狀體與學習的部分，其餘摘結論帶過，並在頁首引言塊與 `intake.md` 明寫這個範圍決定（使用者 2026-11-12 裁示）。六張主圖重製三張。

**它讓 [[c-sparse-coding]] 跨過開頁門檻。** 該頁掛在 [[s-hige-2015-heterosynaptic-plasticity]] 的待開清單上已久，一直只有一篇來源實際使用稀疏編碼去算東西。Minnick 2026 以活化比例與重疊度做了整篇的核心比較，兩篇湊滿門檻。開出來的內容有張力：Hige 2015 在真果蠅量到 12–13%，而 Minnick 2026 照連結體原樣讀出來是 68%。

**這一批最重要的發現，是一個否定句。** 在原樣讀出的網路裡，多巴胺調控的突觸減弱**不是聯結式的**——不給氣味、只給增強訊號，突觸照樣變弱、行為照樣翻轉，兩組在突觸、價性與行為三個層次都分不出來（P＝0.49、δ＝+0.13）。原因是原樣網路的 Kenyon 細胞在沒有任何輸入時仍有 67% 在放電。把嗅葉一類局部神經元的輸出調小之後，學習才恢復成聯結式。**而兩個版本在氣味出現時都是密編碼**，所以讓學習成為聯結式（只給增強訊號不會學）的是「編碼對氣味的依賴」而非稀疏（稀疏管的是氣味之間的專一性，Minnick 2026 單一氣味的身體實驗沒測到；2026-11-16 補註）——這個區分寫進了 [[c-sparse-coding]] 的陷阱 2，並以 [[syn-contradictions]] 3.15 記下「稀疏是聯結學習前提」這個常見說法在庫內其實沒有被檢驗過。

## 階段九（2026-11-21）：第一個不以蕈狀體為中心的研究問題群

**做了什麼。** 使用者放進三篇以視覺為條件刺激的論文：[[s-ofstad-2011-visual-place-learning]]、[[s-vogt-2014-shared-visual-olfactory-circuits]]、[[s-ganguly-2024-visual-inputs-to-kc]]。三個 agent 平行各寫一篇來源頁，再由一個整合者處理共用檔與交叉引用（流程同階段一、三）。**這一批不做冷讀**（使用者 2026-11-21 的決定）。`index.md` 新增一個 H2「視覺的學習與記憶」（tag `visual-learning`），是本庫第一個不以蕈狀體為中心的研究問題群——`CLAUDE.md` 早就預告蕈狀體以外的學習記憶研究「收到論文後會各自成為新的研究問題群」，這一批讓那句預告變成事實，而規則一條都不用改（H2 的值寫進 `tags`，不新增 frontmatter 欄位、不新增目錄層）。

**被什麼逼著改。**

**第一，它是本庫第一次「開一條主題線，只為了記錄還不能裁決」。** 既有六條主題頁都有一個收斂的骨架（KC→MBON 突觸怎麼被多巴胺改變）。[[t-visual-learning-circuits]] 沒有：一篇說視覺位置學習不需要蕈狀體、必要節點在橢球體的 R1 環；一篇說顏色記憶需要蕈狀體的 γ 葉；一篇在全腦連結體裡確認視覺訊息進得了蕈狀體，但完全沒有測功能。開頁門檻（至少兩篇有實質的話要說，**而且說的不一樣**）在這裡是以最強的形式被滿足的，所以那一頁的主要內容就是「為什麼現在還不能說誰對」，`confidence` 標 low。這也讓 [[syn-contradictions]] 第一次有一條矛盾的障礙是**四層疊起來的**（作業類型不同、蕈狀體操作涵蓋範圍未知、細胞顆數還沒有共識、而且分歧雙方對彼此的描述本身就不精確），見 1.13。

**第二，「分歧的雙方對彼此的描述不精確」是一個新的失效點。** Vogt 2014 在討論中點名了 Ofstad 2011，把它與飛行模擬器的研究歸為一類並據此歸因於典範差異；但 Ofstad 2011 用的是**走路的、群體自由的**競技場，不是飛行模擬器。本庫原有的規則只管「不把一篇對**工具**的描述當定論」（癸類）；這一次是一篇對**另一篇的實驗設計**的描述出錯，而那個描述正好是「我們為什麼不一致」這個問題的前提。處理方式是在 1.13 與兩份來源頁各就地標明，不改寫任何一方的結論。

**第三，同一個名詞的三種「稀疏」。** [[c-sparse-coding]] 原本只有活動層的稀疏（一次刺激下有多少比例的 KC 在放電），而 Ganguly 2024 給的是解剖層的稀疏（一顆 KC 接了幾個上游，視覺 KC 為 1–7 個、中位數 3）。兩者可以同時成立也可以互相矛盾——接得少不保證放電得少——所以該頁的「怎麼算」新增一段把兩層分開，並新增陷阱 7；本庫沒有任何來源同時量過這兩者，登記為空缺 3.27。

**第四，門檻一次讓五個邊緣候選過關。** 依「逐一回查其他來源頁的待開頁面清單」這條規則，Vogt 2014 讓四個掛在 [[s-ichinose-2015-reward-recurrent-circuit]] 與自己清單上的候選剛好湊到兩篇（[[e-mb247-gal4]]、[[e-mb008b]]、[[e-dumb2]]、[[e-color-conditioning-arena]]），而 [[c-acquisition-vs-retrieval]] 的「實際使用」其實早就超過兩篇（Vogt 2014、Ichinose 2015、Aso 2014b、Felsenberg 2017），只是沒有人回去數。**門檻的作用是排序不是篩除，而排序只有在有人回頭查清單時才會生效。**

**這一批的更正有兩個方向。** 丙類第 15 條是被**更早**的來源推翻（原始發表比轉述更直接）；庚類第 4、5 條則是表格長大之後，散在不同頁的「另有 N 篇」「N 篇中只有」沒有跟著改——這一次一口氣改了七處，分屬五頁。

**第一，一篇論文大到一個 agent 讀不完，流程必須拆。** 既有的 `ingest-paper` 流程預設「一個 agent 讀完整篇、寫完整頁」。這一篇的文字層 558 KB、圖 42 張，照舊流程做會在讀到一半時爆掉或開始憑印象寫。這次改成三個讀者平行讀（輸入側／輸出側／多巴胺側與討論方法），各自交一份**標滿「待驗證」與原文行號**的事實筆記，再由第四個 agent 拿三份筆記寫頁面，而且**動筆前每個數字與每個否定句都要回原文那一行確認**。這個「筆記是待驗證、不是已完成」的規定是 `CLAUDE.md` 早就寫下的中斷筆記規則，這一次第一次被用在**非中斷**的情境。效果可以量：撰稿者回查後推翻了筆記五項，其中兩項有實質後果（圖 8 的傳遞物質實測型數、圖 26 的典型 MBON 型數）。

**第二，本庫第一次回頭核對自己的二手轉述，而且翻掉了三句。** 這篇在收錄之前已經被庫內九頁引用，全部轉手自別人論文的引言。逐句回查原文的結果：一個百分比是本庫自己算的（乙類第 18 條）；一句「唯一性」的範圍被放大了（丙類第 5 條，**第一次抓到「唯一」來自被引用的論文而不是本庫自撰**）；一句被當成本篇結果的敘述，本篇根本沒有報告（丁類第 22 條）；另有一句主詞被換掉（丁類第 21 條）。**九頁轉述、四句出錯，而出錯的位置全都在「論文沒有說過的話」上。** 這件事給出一條可以一般化的作法：**一篇被庫內多頁引用卻還沒收錄的論文，收錄時要把那些轉述列成清單逐句回查**，而不是只寫新頁。

**第三，「資料集／工具發表」這個體裁第一次真的被用到。** `page-spec` 2.1b 早就列了這一欄（結果 → 資料的組成與已知缺陷；問題與限制 → 用這份資料做什麼分析會出錯），但本庫先前沒有一篇適用。本篇讓它第一次有實例，而且證明這一欄是必要的：論文自陳「蕈狀體葉內超過 80% 的預測突觸已指派，但在 MBON 輸出與 DAN 輸入所在的其他腦區，重建往往遠不完整」——**這一句決定了本篇大約一半的結果要打折**，而論文沒有列出是哪一半，本庫把它列了出來。

**第四，單篇自身不一致一次記了 16 條，是本庫單篇之最。** 以往每篇 2–7 條。數量本身不是問題（86 頁的論文有更多機會對不上），要緊的是其中四條會改變讀者的結論：附檔標題張冠李戴、模型圖說與正文對同一個定義給出相反的邏輯（AND vs OR）、同一個多巴胺亞型的價性在圖說被標反、以及同一條連結在三處指向兩個相反價性的亞型。**這四條都不是算錯，是標籤貼反**——而標籤貼反在連結體論文裡特別危險，因為讀者無法從數字本身察覺。

**第五，開頁門檻又一次因為「第二篇到了」而生效。** [[e-nblast]] 在 2026-11-21 那一批被明確判定**不開**（當時只有 Ganguly 2024 一篇實際使用），這一次因為本篇用它分出 KC 的 14 個亞型與 DAN 的 40 個亞型而過門檻。這是「未過門檻的不是被拋棄，是被降級」這條規則第一次在紀錄上完成一個完整的來回。

**做了什麼。** 新增第四個研究問題群「氣味代碼的刻板性與個體化」（tag `mb-odor-coding`）與它底下唯一的一頁 [[t-stereotypy-to-individualization]]。沒有收錄新論文——這一頁完全由庫內既有的六篇來源組成。

**被什麼逼著改。**

**第一，前十個階段都是「論文進來」推動的，這一個是「讀者問問題」推動的。** 使用者讀網站版 [[s-aso-2014-mb-architecture]] 的科普文第一句，問「真的每隻果蠅都不一樣？」。回查原文的結果是本庫把一句**三手轉述**寫成了定論（丁類第 23 條），而且「近乎隨機」那一半早已被庫內的 [[s-li-2020-mb-connectome]] 修正，只是來源頁的科普文沒跟著改。緊接著的第二個問題是「那對同一隻果蠅來說，學習會不會改變 PN 到 KC 的接線？」——`grep` 全部 28 篇來源頁交叉「PN→KC」與「學習／訓練／配對／可塑」，**零命中**。

**兩個問題剛好是同一條線的兩端**：跨個體是否固定、同一個體內是否會變。這一對問題在本庫既有的三個問題群底下都沒有歸屬——前三群問的都是「學習如何發生」，而這一對問的是**學習之前**那張代碼表。於是第四個 H2 成立。這件事值得記錄的理由不是多了一頁，而是：**一個會累積的知識庫，開新線的訊號可以來自讀者讀不通的地方，而不只是來自新論文。**

**第二，開頁門檻的「說的不一樣」第一次用在「同一個問題的三種問法」上。** 庫內三篇都在問「KC 的取樣隨不隨機」，表面上像重複。拆開之後是三件不同的事：單顆 KC 的輸入組合可不可預測（Aso 2014a 引述前人，說不可預測）、型別層級有沒有偏好（Li 2020 實測，有，但幅度小且 γ 型看不到）、同一型在不同個體之間是否一致（Ganguly 2024 的檢定**分不開隨機與刻板兩個模型**）。三個答案彼此不衝突也不互相支持，所以它們構成一條線而不是三份重複的筆記。判定門檻時把問題拆細，是這一次的作法。

**第三，第一次用「庫內另一篇的參考文獻」解除一條 `？待查`。** [[s-aso-2014-mb-architecture]] 的討論節引「Hige et al. 未發表」支撐「同一型 MBON 的氣味反應在不同果蠅之間不一樣」，本庫原先標了 `？待查`（那份資料後來以哪一篇發表）。這次由庫內 [[s-hige-2015-heterosynaptic-plasticity]] 的參考文獻與**同語境的引用句**確認為 Hige, Aso, Rubin & Turner 2015, *Nature* 526:258–262。先前解除 `？待查` 都靠取得原始資料（補充圖、影片），這是第一次靠庫內交叉引用完成，而且它能成立的前提是本庫逐篇抄下了參考文獻的完整出處。**那篇本身仍未收錄**，所以「個體化」這一端目前沒有第一手證據，已寫進新主題頁的缺口。

**第四，這一頁記錄的是一個本庫答不出來的問題。** 「學習會不會改變萼部的接線」在本庫是空的，而且空的原因是結構性的：電子顯微鏡連結體是終點量測，同一隻果蠅沒有訓練前的接線圖可比。主題頁因此明寫「沒有人測過，不是已被否證」——這是本庫第一次有一條主題線以「這個問題在現有方法下問不出來」作為它的收尾。
