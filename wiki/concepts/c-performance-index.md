# 表現指數（performance index, P.I.）

**表現指數是嗅覺學習行為測驗的分數：訓練後讓一群果蠅在兩個氣味之間選擇，把選擇的分布換算成一個數字，代表這群果蠅學到了多少。** 分數越高表示越多果蠅避開（或趨近）被訓練的氣味；分數接近 0 表示選擇與隨機無異。

**本頁用語**（每頁可單獨查閱，故重複列出）：

- **DAN**：多巴胺神經元（dopaminergic neuron），送出代表懲罰或獎賞的多巴胺。依 Handler 2019 的說法，PAM 群多報告獎賞、PPL（PPL1）群多報告懲罰。
- **光**：指光遺傳活化 DAN，即讓 DAN 帶上照紅光就放電的蛋白，用光代替真的懲罰或獎賞（見 [[c-us-substitution]]）。

## 怎麼算 / 怎麼判定

## 引用時的陷阱

1. **兩篇的 P.I. 刻度不同。** Tomchik 2009 的值落在 0–1；Hige 2015 圖上的值在數十，上下限與換算方式都 ？待查，跨篇不要直接比數值。
2. **正負號方向不同。** Hige 2015 的 PI 正值＝迴避；Handler 2019 的位移正值＝吸引。並列時要先對齊方向。
3. **n 是「次」不是「隻」。** P.I. 是一群果蠅算出一個數；Tomchik 2009 的 n＝6 是 6 次 P.I.，每群幾隻 ？待查。Handler 2019 的統計單位同樣是盒。
4. **行為與生理常不是同一批果蠅。** Hige 2015 的 PI 與突觸記錄來自不同果蠅、不同光協定（行為 500 ms × 12，生理 1 ms），兩者是對應不是因果。
